# VitalCare Hospital Website

A modern responsive hospital website scaffold built with HTML, CSS, and JavaScript.

## Included files

- `index.html` — Home page
- `services.html` — Services overview
- `doctors.html` — Doctor profiles
- `about.html` — About and mission
- `contact.html` — Contact and appointment form
- `css/styles.css` — Responsive styling
- `js/main.js` — Mobile menu and contact form handling

## Getting started

Open `index.html` in your browser to view the site.

For a local development server, you can use one of these commands in the repository root:

- `python -m http.server 8000`
- `npx serve .`

Then visit `http://localhost:8000`.

## Customization

- Update page content in the HTML files.
- Adjust colors, spacing, and layout in `css/styles.css`.
- Add additional pages or components as needed.
